# Ayansha Health Care Doctor Panel

## Phase 1 capabilities
- Doctor profile and specialty
- Appointment queue
- Patient details
- Appointment status management
- Prescription workflow foundation
- Video consultation entry point

## Planned API routes
- GET /api/doctor/appointments
- PATCH /api/doctor/appointments/:id/status
- POST /api/doctor/prescriptions
- GET /api/doctor/patients/:id

The panel will consume the shared backend and PostgreSQL data layer.
